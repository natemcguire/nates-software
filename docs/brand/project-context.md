# Project context (for naming/brand brief — codenamed "fork marketplace", no name chosen yet)

## What it is
A consumer-facing marketplace + git platform where every app is forkable:
- Product Hunt-style daily leaderboards, upvotes, launch days, maker culture.
- Every listing is a real git repo. Fork it, modify it with AI agents (hosted browser
  terminal or local `git clone` + your own tools), and pull individual FEATURES from
  any other fork in the family — AI semantic merge handles diverged code.
- Creators price apps free / one-time / subscription; revenue splits down the fork
  ancestry chain. Individual feature packages are also sellable. Free apps carry an
  ad-slot scaffold for a later ads pool.
- Underneath: a self-hosted git engine ("like Torvalds built it for an AI-native
  world") with a merge queue designed for agent-speed merging (100x human PR cadence),
  reliability positioned as better-than-GitHub. Power users get "XTREME MODE" — raw
  git over SSH, feature-to-commit-range mappings, live merge queue.

## Audience
- Primary: non-technical "normies" who want to own and customize software without
  being git users (git fully abstracted behind plain-language actions).
- Secondary: AI-native builders and developers (XTREME MODE).
- Demographic target: Millennials to older Gen Z (~25–45 in 2026).

## Aesthetic / personality direction (already decided)
- Windows 95 chrome (bevels, title bars, system sounds) played straight but FUN.
- Nate's Software information density: spec sheets, benchmark bar charts, real numbers
  everywhere ("avg merge time 41s" shown off like a benchmark score).
- Product Hunt popularity mechanics: daily drops, leaderboards, streaks, badges.
- Nostalgic-but-functional; the audience trusts benchmark tables over gradient hero pages.

## Positioning question still open (brief should support BOTH, not decide)
- Editorial-led ("trusted reviewer voice" à la Nate's Software, founder writes reviews)
- vs community-led (pure Product Hunt crowd ranking)
- vs hybrid (community platform with an editorial column inside).

## Cultural lineage
Homebrew-adjacent: the spirit of the Homebrew Computer Club, ROM-hacking and mod
scenes — a community of makers who tinker, swap builds, and show off. The twist:
AI makes non-devs full members of that club for the first time. "The new makers
don't solder or code — they still make."

## Key differentiators to capture in brand language
1. Fork = ownership. You don't download apps, you own a modifiable copy.
2. Features flow between forks (down, sideways, upstream) — network > single maintainer.
3. AI does the merging; undo is always safe; everything is real git underneath.
4. Money flows down the fork tree — creators earn from descendants forever.
5. The git engine itself is a reliability/speed moat vs GitHub.
