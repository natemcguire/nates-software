01How it got proven — the part most demos skip

Anyone can show a happy-path deploy. The real question is whether a brand-new app deploys with no hand-holding. Each layer of real testing caught what the layer before it couldn't — which is exactly why the review ran to the end instead of stopping at "the tests pass."

Live end-to-end test of all four lanes

Pushed fresh apps through the real pipeline. Every gate passed — but it surfaced 4 first-deploy blockers. Postgres provisioning was 100% broken; container image repos were never auto-created. The existing apps only worked because they'd been hand-assembled earlier.

An adversarial code review of the deploy engine

An independent reviewer went at the ~3,700-line diff. Six findings — the serious ones fixed immediately, the rest filed with the exact conditions that would make them matter. Confirmed clean: database credentials never leak into a build log.

The fresh-app gate — the honest one

A genuinely new app (hello-pg2), nothing pre-made, went push → live URL writing to a real database. It also caught one last bug: a YAML flaw in the Next.js deploy that only a real deploy — never a unit test — could reveal.

Fix, re-deploy, and confirm live

Next.js redeployed through the corrected pipeline; the page's render timestamp changes on every request, proving genuine server-side rendering. Through all of it: zero production outage — every failed redeploy kept serving its last healthy version.

02What shipped, and what's honestly still open

Building in public means showing the backlog too. Everything in the top group is live. The follow-ups are real but gated — none of them affects a single developer using the platform today; they're the hardening you do before a second user shows up.

Under the hood: a wildcard router Worker as the single front door (adding an app is one database row, not a DNS change), Cloud Native Buildpacks turning any repo into a runnable image with no Dockerfile, and a control plane that learns build results by verifying the image digest — never by trusting a callback from untrusted build code. The tier boundary is the cloud boundary: free is Cloudflare and scales to zero; always-on paid is AWS kept warm.
